
# Amazon Clone

A simple Amazon Clone website built using HTML, CSS, and JavaScript.

## Features
- Amazon-style Header and Navbar
- Product Cards with Images
- Add to Cart Button
- Working Cart Counter
- Search Bar Design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project.
2. Open index.html in your browser.

## Project Purpose
This project was developed as part of a Web Development Internship.

## Note
This is a basic frontend project for learning purposes.
